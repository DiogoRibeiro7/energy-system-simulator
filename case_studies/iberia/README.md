# Iberian Approximation Case Study

This case study is a transparent two-zone Portugal-Spain electricity-system
approximation. It is useful for exercising the simulator on a recognisable
research workflow, but it is not a reconstruction of the full Portuguese or
Spanish grids.

## Scope

- Study period: 2024-06-24 00:00 UTC through 2024-06-30 23:00 UTC.
- Resolution: hourly.
- Topology: one Portugal bus (`pt`), one Spain bus (`es`), and one directed
  Portugal-to-Spain interconnector (`pt-es`).
- Positive `line_flow_mw__pt-es` means Portugal exports to Spain; negative flow
  means Spain exports to Portugal.
- Demand and installed-capacity targets are calibrated from Ember 2024 annual
  country aggregates.
- Hourly demand, weather, hydro inflow, and prices are deterministic
  approximations generated by the local build script.

## Reproducible Commands

Generate the committed input snapshot, configuration, scenario file, provenance
target table, and report scaffold:

```bash
poetry run python case_studies/iberia/scripts/build_case_study.py
```

Refresh baseline and sensitivity outputs, then rewrite the report with results:

```bash
poetry run python case_studies/iberia/scripts/build_case_study.py --run --overwrite
```

Run the baseline directly through the CLI:

```bash
poetry run energy-sim simulate --config case_studies/iberia/configs/iberia_baseline.yaml --overwrite
```

Run the sensitivity experiment directly:

```bash
poetry run energy-sim scenario-experiment --experiment case_studies/iberia/scenarios/iberia_sensitivity.yaml --resume --no-plots
```

Outputs are written under `case_studies/iberia/outputs/`, which is intentionally
separate from the package's default `outputs/example` workflow.

## Files

- `data/iberia_2024_week_hourly.csv`: small generated hourly input snapshot.
- `configs/iberia_baseline.yaml`: two-zone baseline model.
- `scenarios/iberia_sensitivity.yaml`: configuration-only sensitivity cases.
- `provenance/ember_2024_targets.csv`: derived aggregate targets from Ember.
- `provenance.md`: source, licence, transformation, and caveat record.
- `reports/case_study_report.md`: case-study assumptions, validation, results,
  and limitations.

## Sensitivities

The scenario experiment includes:

- 25% additional solar capacity in both countries.
- 50% additional Portugal-Spain transfer capacity.
- 30% gas fleet derating as a thermal-retirement proxy.
- Reduced hydro turbine efficiency as a drought-output proxy.
- 50% additional battery power and energy.
- Higher carbon price.

These are stylized counterfactuals. They should be interpreted as model
responses to transparent parameter changes, not as policy forecasts.
