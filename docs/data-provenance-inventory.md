# Committed Data Provenance Inventory

This inventory covers CSV data committed for the 1.0 release.

| Path | Classification | Licence or provenance |
|---|---|---|

| `data/hydro_seasonal_hourly.csv` | Synthetic example | Generated fixture for hydro dispatch examples. |

| `examples/data/public_weather_sample.csv` | Tiny public-data adapter sample | Local fixture used to demonstrate adapter transformations; not an official weather archive. |
| `tests/fixtures/public_data/*.csv` | Test fixtures | Minimal synthetic and edge-case CSVs used for validation tests. |

No committed CSV is intended to be a complete official operational dataset.
Case-study outputs should cite the repository citation metadata and the local
case-study provenance file.
