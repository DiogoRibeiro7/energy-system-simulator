# Expected Outputs

Running the study produces:

- `outputs/summary.csv`
- `outputs/research_manifest.json`
- per-scenario output directories with `summary.json`, `timeseries.csv`, and
  `scenario_manifest.json`
- `tables/metrics.md` and `tables/metrics.tex`
- `tables/comparisons.md` and `tables/comparisons.tex`
- `tables/uncertainty.md` and `tables/uncertainty.tex`
- `figures/storage_value_objective.png`
- `figures/storage_value_curtailment.png`
- `figures/figure_metadata.json`
- `reports/report.md`
